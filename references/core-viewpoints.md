# Core Viewpoints

Use `08-core-viewpoints.md` for stable beliefs, principles, role definitions, and
judgment frames that should shape future work but are not concrete decisions or
repeatable workflows yet.

## What Belongs Here

- confirmed project philosophy
- stable evaluation criteria
- user belief structures that recur across tasks
- durable role definitions for Codex
- principles distilled from multiple conversations or source cards

## What Does Not Belong Here

- one-off opinions
- attractive source claims the user has not endorsed
- temporary preferences
- concrete decisions with clear action consequences
- step-by-step workflows

Use:

- `02-user-preferences.md` for stable collaboration preferences
- `03-decisions.md` for concrete choices
- `04-workflows.md` for repeatable procedures
- `06-memory-candidates.md` for unconfirmed viewpoints
- source cards for external material that should not yet be internalized

## Promotion Rules

Only promote a candidate into `08-core-viewpoints.md` when at least one is true:

- the user explicitly confirms it as their view
- it has appeared consistently across multiple tasks
- it directly shapes future reasoning or evaluation
- a source card has been discussed and the user confirms the lesson should be internalized

If unsure, keep it in `06-memory-candidates.md` and ask for confirmation.

## Suggested Entry Shape

```md
## YYYY-MM-DD: Viewpoint Title

- Viewpoint:
- Why it matters:
- Evidence or source:

- Related preferences:

- Related workflows:
```
