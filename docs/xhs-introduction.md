# 用 Codex Second Brain，把 Codex 变成你的第二大脑

Codex 现在是市面上最强的通用 AI 智能体之一。

它不仅可以用来写代码，还可以帮你写文档、跑自动化，甚至可以变成一个真正懂你的个人知识管理助手。

但这里有个前提：你需要给 Codex 一套可以持续读取、持续更新的记忆系统，让它不只是记住你，还能根据你的新信息不断进化。

所以我做了一个 skill：`codex-second-brain-memory`。

这个 skill 专门帮你快速把自己的 Codex 变成一个独属于自己的第二大脑。

它会帮 Codex 建一套“分层记忆系统”。让它把记忆分清楚：哪些是项目规则，哪些是你的长期偏好，哪些是已经确认过的决策，哪些只是一次对话里出现的候选想法，哪些是可复用工作流，哪些是外部文章和书里的资料，哪些是新旧信息之间的冲突。它不会把所有聊天记录一股脑塞进一个大文件，而是让每一种记忆都有自己的位置。

更重要的是，它不是一次性整理，而是可以持续进化。你和 Codex 的每一次对话里，如果出现了有价值的信息，它会先判断这句话到底是什么：只是临时想法，还是可以复用的偏好？只是一个观点，还是已经影响了之后的行动？如果还不确定，就先放进候选记忆；如果你确认了，它就可以升级成长期偏好；如果这个偏好反复影响项目选择，它还可以继续上升成观点、原则，甚至变成明确决策或固定工作流。也就是说，它不是“保存聊天”，而是在帮你把零散对话慢慢提炼成真正可复用的认知结构。

它还可以处理你读过的文章和书。你给它一篇文章、一个链接、一本书摘录，它不会只给你做一个普通摘要，而是会帮你拆成读书笔记：作者原本在说什么，核心结构是什么，关键证据是什么，哪些观点对你当前项目有用，哪些只是外部观点，不能直接内化。真正有价值的内容，会先进入资料卡片；如果它持续影响你的判断，再进入候选记忆；经过确认后，才会上升到你的长期记忆、核心观点，甚至成为你的角色设定、项目原则或决策依据。

拥有了这个 Skill，就可以让 Codex 学会区分、沉淀和升级记忆。它会把一次对话变成候选记忆，让候选记忆变成稳定观点，再把稳定观点变成决策和工作流，最后还可以反过来影响下一次 Codex 怎么理解你、怎么读资料、怎么做事。

使用方法：

步骤 1

点击笔记下方 RedSkill Codex 第二大脑链接。

步骤 2

点击按钮“去使用”，并复制口令。

步骤 3

在 Codex 中发送这段口令后等待安装完毕。

步骤 4

重启 Codex，并在你想要建立第二大脑的项目里发送：

```text
请使用 codex-second-brain-memory，在当前项目里为我构建一套文件化第二大脑。先检查现有项目结构，不要覆盖已有文件；把项目规则、用户偏好、已确认决策、可复用工作流、资料卡片、候选记忆和冲突更新分别放到正确文件里。完成后告诉我新增或修改了哪些文件，以及哪些候选记忆需要我确认。
```

步骤 5

等 Codex 扫描项目并生成记忆文件。它会自动判断哪些内容应该放进项目规则、用户偏好、决策、工作流、资料卡片、候选记忆和冲突更新里。

步骤 6

检查 Codex 输出的候选记忆。如果它把某些内容标成“需要确认”，你可以告诉它：

```text
这条确认，写入长期记忆。
这条只是临时想法，先不要保存。
这条以后作为我的固定偏好。
```

步骤 7

以后每次开始重要任务前，可以先说：

```text
请先读取我的第二大脑，再开始这个任务。
```

每次完成重要任务后，可以说：

```text
请做一次第二大脑收尾，把这次值得保留的内容更新进去。
```
